# portfolio

Uns scripts que eu fiz pra resolver problema de cliente pequeno. Nada de framework, nada de arquitetura. Só o que funciona.

- **bot_telegram** – atendimento automatico com cardapio e carrinho
- **scraper_preco** – monitora preco de produto e avisa quando muda
- **automacao_planilha** – le csv/xlsx, agrupa, soma e cospe relatorio em excel
- **cotacao_dolar** – bot que envia cotacao de dolar/euro/bitcoin no telegram
- **baixar_pdfs** – baixa todos os PDFs de uma pagina web de uma vez
